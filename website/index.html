Technology

Simple, explainable and tested.

🧠

AI anomaly detection

An Isolation Forest learns each chamber’s normal pattern and flags drift early.

🧪

Spoilage estimation

Degree-hours above the limit give a clear low, moderate or high risk score.

🔗

Audit chain

Readings are hash-chained, so any edit to the record can be detected.

🔐

Role-based access

Owner, manager, site manager, technician, accountant, viewer and farmer each see only what they need.

🗣️

Hindi first

Alerts and the farmer page are written in Hindi, with English alongside.

🔌

Open API

A FastAPI backend so other systems can read data and receive alerts.
